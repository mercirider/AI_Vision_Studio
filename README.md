## ✨ Features

### 🎨 AI Image Generation
| Feature | Description |
|---------|-------------|
| 🤖 **AI-Powered** | Pollinations AI (Flux model) — free, no API key |
| 🎭 **6 Art Styles** | Realistic, Anime, Cyberpunk, Watercolor, 3D, Sketch |
| 📐 **4 Aspect Ratios** | 1:1, 16:9, 9:16, 4:3 |
| ✨ **HD Enhancement** | Quality boost toggles |
| 🎲 **Surprise Prompts** | 20+ pre-made creative prompts |
| 🌱 **Seed Control** | Consistent results |
| 💡 **Smart Tips** | Quick prompt enhancers |

### 💬 AI Chat Assistant
| Feature | Description |
|---------|-------------|
| 🧠 **Smart Responses** | Context-aware replies |
| 💡 **Multiple Topics** | Coding, jokes, AI, motivation |
| ⌨️ **Typing Indicator** | Realistic AI feel |
| 💭 **Suggestion Chips** | Quick conversation starters |
| 🕐 **Timestamps** | Message history with time |
| 🎯 **Enter to Send** | Fast messaging |

| Feature | Description |
|---------|-------------|

| 🎨 **Masonry Grid** | Beautiful responsive layout |
